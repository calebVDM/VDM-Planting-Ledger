Import this season's plantings

Upload a CSV or paste rows copied from your spreadsheet. Expected columns: SKU (e.g. your "VDM SKU" column — used as the unique code on each tag), Crop, Variety, Quantity, Unit, Planting Date (headers matched loosely, order doesn't matter). Rows without a SKU get an auto-generated code instead.

Once you've hosted this file (GitHub Pages, Netlify, etc.), paste that public URL here. QR codes will then open a phone straight to that item for a one-tap scan — no photo capture needed. Leave blank to keep QR codes as plain codes for the in-app scanner. This is saved in your Google Sheet's Settings tab, so it's shared across everyone using the app.

Print barcode tags

Each tag has a scannable QR code and prints at exactly 2″ × 2″ — sized for standard 2×2 label sheets. In the print dialog, set scale to 100% ("Actual size" / turn off "Fit to page") so labels come out true to size.

Scan a tag

Scan In records the exact quantity when production starts. Scan Out records the date a crop completely sells out. If an app link is set up (Import tab), your phone's regular camera app can scan a tag and jump straight here — this in-app scanner is the fallback.
